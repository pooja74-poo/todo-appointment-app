# 🗓️ To-Do Appointment App

[🟢 View the Live Site on Netlify](https://todo-appointment.netlify.app/)

A beautifully styled, full-stack React application that lets users register, log in, and manage personal appointments. Built with modern design and real-world architecture, it's perfect for showcasing frontend/backend skills.

---

## 🚀 Features

- 🔐 User registration and login with session tracking (cookies)
- ➕ Add new appointments
- 📝 Edit existing appointments
- ❌ Delete appointments with confirmation
- 🧾 Personalized user dashboard
- 📱 Fully responsive and styled using Bootstrap 5
- ⚛️ React Router + React Icons
- 💻 JSON Server for mock backend API

---

## 🛠 Tech Stack

**Frontend**: React.js, Bootstrap 5, React Router, Formik, React Icons  
**Backend (local only)**: JSON Server (mock REST API)  
**Deployment**: Netlify
